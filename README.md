# React Investment Calculator

A simple investment calculator built with React as part of a React learning exercise.

The application allows users to enter their initial investment, annual investment, expected annual return, and investment duration. Based on these values, it calculates and displays the projected investment results for each year.

## 🚀 Features

- Initial investment input
- Annual investment input
- Expected annual return input
- Investment duration input
- Automatic investment calculations
- Year-by-year investment results
- Currency formatting using the JavaScript `Intl` API
- Responsive input layout
- Component-based React structure

## 🛠️ Technologies

- React
- JavaScript
- Vite
- HTML
- CSS
- JavaScript `Intl.NumberFormat` API
